# web-saas Profile Requirements

A project using this profile must resolve frontend rendering/routing, API semantics, authentication and backend authorization, data ownership/migrations, browser security, observability, deployment and recovery. Optional surfaces such as payments, AI, files, realtime, search, and PWA are out of scope until explicitly enabled.

`disabled` means the capability is not part of the current release and coding agents must not add it speculatively. `optional_enabled` means the complete extension obligation pack applies. `required` is reserved for profile-mandated capabilities.
