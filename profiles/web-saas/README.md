# web-saas Profile 2.0.0

This profile activates production-grade specification obligations for browser-based SaaS systems while leaving stack choices to the target project. Generic Core remains authoritative for lifecycle, authority, audit, work-package, and release semantics.

Required capabilities are `frontend`, `api`, `auth`, `authorization`, `database`, and `observability`. Optional capabilities are disabled unless explicitly enabled in project configuration. Enabling an extension activates its documentation, validation, testing, audit, and work-package obligations as one unit.
