# Web Threat Model Template

Inventory actors/assets/trust boundaries and applicable threats: authentication bypass, authorization/tenant isolation, CSRF, CORS, XSS, clickjacking, injection, SSRF, file upload, session/token replay, secret leakage, webhook spoofing, open redirect, mass assignment, dependency/supply-chain and privileged admin misuse. Each applicable surface requires mitigations and test evidence; `NOT_APPLICABLE` requires evidence.
