# Frontend Architecture Template

## Rendering and routing
Record rendering model, routing authority, browser support, responsive targets, protected-route bootstrap, deep-link/404 behavior, and PWA/offline behavior.

## State boundaries
Name the server-state mechanism, local UI state boundary, form/validation boundary, authentication state owner, generated API type source, and private data caching policy.

## Screen state contract
For each critical screen resolve loading, loaded, empty, partial, unauthorized, forbidden, validation error, network error, server error, and offline behavior.

## Accessibility
State the accessibility target and keyboard/focus/error-announcement obligations. Frontend permission checks are UX only; backend authorization remains authoritative.
