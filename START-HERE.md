# Start Here

This repository implements `ShipGate`.

1. Read `README.md` and the approved design spec.
2. Use `task setup` to create the locked development environment.
3. Use the `shipgate` (or `workflow`) CLI for project operations.
4. Use `task qa` before commits that claim a clean repository.

`BUILD_READY` means the generated specification is ready for a coding agent. It does not mean the target application has been runtime-verified or proven production-ready.
