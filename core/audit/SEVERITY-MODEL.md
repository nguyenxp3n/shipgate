# Severity Model

- **CRITICAL** — can cause security boundary failure, cross-tenant exposure, data loss, impossible authoritative contract, credential leakage, or similarly catastrophic implementation behavior.
- **HIGH** — load-bearing contract, ownership, correctness, or operability defect likely to produce a materially wrong implementation.
- **MEDIUM** — meaningful defect with bounded impact or a viable documented workaround.
- **LOW** — limited-risk clarity or polish defect.

Severity describes shipped effect, not how difficult the fix is.
