Initial release of the AI Project Finalization Workflow V2 specification factory.

Included in this release:
- Generic Core lifecycle, authority, governance, audit, readiness, and release model.
- `web-saas@2.0.0` profile and optional capability packs.
- Generic, Codex, Claude Code, and Gemini/Antigravity adapters.
- Deterministic schemas, validators, generators, work-package compilation, audit closure, staleness, and release integrity machinery.
- TeamNotes executable reference project, invalid fixtures, HCN-derived regression lessons, agent role evaluations, and self-hosting validation.

Assurance claims are evidence-driven. Build readiness is not runtime or production validation of a target product.
